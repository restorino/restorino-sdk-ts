1. BACKEND & DATA LAYER INTEGRATION (NO MOCK DATA)
================================================================================
The backend is already implemented and exposed via a unified local TypeScript SDK located at `@/lib/api` (an instance of `RestorinoClient`).
DO NOT mock network calls. Always import `api` from `@/lib/api` to fetch and mutate real data.

The SDK exposes 7 specialized modules:

1. `api.vitrine`:
   - `getRestaurant(id?)`: Restaurant profile, logo, cover banner, description, cuisines, opening hours, currencies.
   - `getMenu(id?)`: Full menu with categories, products, allergens, supplements, garnishes, sizes.
   - `checkDeliveryZone(lat, lng)`: Real-time GPS eligibility verification for home delivery.
   - `getStatus(id?)`: Live restaurant status badge (Open / Closed, current shift).
   - `getReviews(id?, page, size)`: Verified public customer testimonials and ratings.
   - `search(filter)`: Multi-criteria restaurant search by GPS, cuisine, city.
   - `getCategoryBySlug(slug)`: Category by SEO slug.
   - `getProductBySlug(categorySlug, productSlug)`: Dish by SEO slug.
   - `getSeoMeta()`: Homepage SEO meta tags.
   - `getTestimonialsBySubdomain(subdomain)`: Verified reviews by vitrine subdomain.
   - `getTestimonials(restaurantId)`: Verified reviews by restaurant ID.
   - `validateApiKey()`: Validates storefront API key permissions and active status.
   - `getConfig()`: Full vitrine configuration, brand colors and custom sections.
   - `getPublicConfig()`: Public published vitrine configuration.
   - `getSchemaOrg()`: Official JSON-LD Schema.org rich-snippet bundle for Google search.

2. `api.orders`:
   - `placeOrder(orderPayload)`: Place public order (supports DELIVERY, TAKEAWAY, and DINE_IN).
   - `estimateDelivery(customerLocation)`: Calculates real-time delivery fee and ETA in minutes.
   - `trackOrder(orderId, { customerEmail, customerPhone })`: Real-time order preparation status with 2-factor anti-IDOR security.
   - `trackOrderByToken(token)`: One-click tracking via signed SMS/email link.
   - `getOrderingMenu()`: Menu items optimized for checkout.
   - `getSettings()`: Public restaurant settings (tax rate, currency, accent colors).
   - `cancelOrder(orderId, { customerEmail, customerPhone, reason })`: Cancel pending order with verification.
   - `createReservation(reservation)`: Book a table online with date, time, party size, notes.
   - `trackReservation(reservationNumber, { customerEmail, customerPhone })`: Track table reservation status.
   - `cancelReservation(reservationNumber, { customerEmail, customerPhone, reason })`: Cancel a table reservation.

3. `api.delivery`:
   - `track(trackingNumber)`: Public courier live tracking (status, driver name, masked phone, live GPS coordinates, ETA).

4. `api.tables`:
   - `getTableInfo(tableId)`: Table number, capacity, zone, and active session from QR code for contactless dine-in ordering.

5. `api.liveAgent`:
   - `connect({ restaurantSlug, onTranscript, onAudio, onClientAction, onStatusChange, onInterrupted })`: Interactive bidirectional voice/chat culinary assistant powered by Gemini Live. Supports voice ordering (`ADD_TO_CART` client actions) and personalized dish recommendations.
   - Session supports typed EventEmitter: `session.on('transcript', cb)`, `session.on('action', cb)`, `session.on('audio', cb)`.

6. `api.auth`:
   - `login({ email, password })`: Authenticates customer, stores JWT & refresh token automatically.
   - `loginWithGoogle({ googleToken })`: Google Sign-In authentication and instant account creation.
   - `register({ email, password, firstName, lastName, phone, referralCode })`: New customer registration.
   - `refreshToken()`: Refreshes access token (also handled automatically on 401).
   - `getMe()`: Current customer session info & loyalty tier summary.
   - `logout()`: Clears local session and revokes server tokens.
   - `changePassword({ currentPassword, newPassword })`: Updates password.
   - `requestEmailVerification()`, `verifyEmail(token)`: Email verification flow.
   - `requestPasswordReset(email)`, `confirmPasswordReset(data)`: Secure password recovery.

7. `api.customer`:
   - `getProfile()`, `updateProfile(data)`: Customer profile details.
   - `getOrders(page, size)`: Order history with instant re-order and rating modal.
   - `getOrderDetails(orderId)`: Detailed breakdown of past order.
   - `rateOrder(orderId, rating)`: 1 to 5 stars for food quality, delivery speed, service + review text.
   - `getReferrals()`: Referral dashboard, unique shareable link, list of referred friends, points earned.
   - `applyReferralCode(code)`: Apply a friend's referral code.
   - `validatePromoCode(code, cartAmount)`: Validate promo coupon and calculate discount.
   - `getNotifications(page, size)`: Customer in-app inbox notifications.
   - `getUnreadNotificationCount()`: Unread badge count.
   - `markNotificationRead(id)`, `markAllNotificationsRead()`: Inbox read status.
   - `submitTestimonial(data)`: Submit restaurant reviews.
   - `getMyTestimonials()`: Customer's own reviews.

8. `api.loyalty`:
   - `getStatus()`: Points balance, current tier (`BRONZE`, `SILVER`, `GOLD`, `PLATINUM`), progress percentage to the next tier.
   - `getRewards()`: Catalog of redeemable rewards (free dishes, discounts).
   - `redeemReward(rewardId)`: Exchange points for instant coupon code.
   - `getGoogleReviewInfo()`: Reward points offered for leaving a Google review.
   - `getGoogleReviewStatus()`: Check if customer is eligible to claim points for a review.
   - `claimGoogleReview({ reviewerName, rating, reviewComment })`: Claim bonus loyalty points.
   - `uploadGoogleReviewProof(file)`: Upload screenshot proof of Google review.
