────────────────────────────────────────────────────────────────────────────
1. INSTALL & INIT (exact)
────────────────────────────────────────────────────────────────────────────
npm install @restorino/sdk

// src/lib/api.ts
import { RestorinoClient } from '@restorino/sdk';

export const api = new RestorinoClient({
  baseUrl: import.meta.env.VITE_RESTORINO_API_URL ?? '',
  restaurantId: import.meta.env.VITE_RESTAURANT_ID, // restaurant UUID
  credentials: 'include',                            // REQUIRED (cookie auth)
  retries: 2,
  onTokenExpired: () => { window.location.href = '/login?expired=true'; },
});

env:
  VITE_RESTORINO_API_URL=https://api.restorino.com
  VITE_RESTAURANT_ID=<restaurant-uuid>

────────────────────────────────────────────────────────────────────────────
2. NON-NEGOTIABLE RULES
────────────────────────────────────────────────────────────────────────────
R1. Auth is COOKIE-BASED. login()/register() return { customer, loyalty } and
    NO token. Never read response.token. Check the session with api.auth.getMe().
R2. Never persist tokens: do NOT set storageType to 'localStorage'.
R3. No API key exists in this SDK. The only credential is the customer cookie.
R4. Never send `total`/`tax` when creating an order — the server recomputes.
R5. restaurantId is a UUID. A slug is only accepted by getRestaurant,
    getCategoryBySlug, getProductBySlug, getSeoMeta*, getPublicConfig,
    getSchemaOrg.
R6. Money = number. Dates = ISO strings. Create-reservation date = ISO datetime
    without trailing Z, e.g. '2026-12-24T20:30:00'.
R7. Only call the methods listed in §3. Nothing else exists.
R8. STOREFRONT SCOPE: only /api/public/**, /api/auth/customers/**,
    /api/customers/**, /api/notifications/customers/** and public vitrine reads.
    Anything else throws OUT_OF_SCOPE_ENDPOINT (admin, POS, driver, staff).

────────────────────────────────────────────────────────────────────────────
4. ENUMS (exact)
────────────────────────────────────────────────────────────────────────────
deliveryMethod : 'delivery' | 'takeout' | 'dine-in'      (request, lowercase)
orderType      : 'DELIVERY' | 'TAKEOUT' | 'DINE_IN'      (response, uppercase)
paymentMethod  : 'card' | 'cash' | 'paypal' | 'stripe' | 'mobile'
orderStatus    : PENDING CONFIRMED PREPARING READY OUT_FOR_DELIVERY DELIVERED
                 COMPLETED CANCELLED REFUSED REFUNDED PENDING_VERIFICATION
deliveryStatus : PENDING ASSIGNED PICKED_UP IN_TRANSIT DELIVERED FAILED CANCELLED
reservation    : PENDING CONFIRMED CANCELLED COMPLETED NO_SHOW
table          : AVAILABLE OCCUPIED RESERVED CLEANING BLOCKED MERGED
rewardType     : DISCOUNT PERCENTAGE FREE_ITEM CASHBACK CUSTOM

PENDING_VERIFICATION = first-time cash order awaiting confirmation. Not an error.

────────────────────────────────────────────────────────────────────────────
7. DELIVERABLES
────────────────────────────────────────────────────────────────────────────
1. Menu page: categories → dishes, prices, allergens, add-to-cart with extras.
2. Cart + checkout: delivery | takeout | dine-in; address or geolocation;
   delivery estimate; promo code; order confirmation with orderNumber.
3. Tracking page: order watch + courier map when delivery.
4. Reservation form: guests, ISO datetime, GPS optional.
5. Auth: login / register / Google; guarded routes via getMe(); logout.
6. Account: profile, order history, ratings, notifications, referrals.
7. Loyalty: points, tier, reward catalog, redeem, Google review claim.
8. Optional voice agent with confirmAction() before applying cart changes.
9. Error handling for 400/401/402/403/404/409/429 via RestorinoApiError;
   show err.requestId when present.
10. Optional: onRequest/onResponse hooks for logging (no headers, no query).

────────────────────────────────────────────────────────────────────────────
8. DEFINITION OF DONE
────────────────────────────────────────────────────────────────────────────
- No `response.token`, no localStorage token, no browser API key.
- Order payload has deliveryMethod + lowercase paymentMethod + item totalPrice.
- No total/tax submitted.
- restaurantId is a UUID.
- Polling watchers stopped on unmount.
- `grep` for §6 left column returns zero hits.
